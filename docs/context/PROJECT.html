Project

Dranx Prediction League is an unofficial prediction game for a private invited group covering the 2026/27 English Premier League. A participant completes one immutable three-stage entry: order exactly 20 clubs and enter one display name, choose all seven spotlight predictions, then review the whole package before submission. The categories are top scorer, top assister, most clean sheets, underdog team, overrated team, underdog player, and overrated player. The first, second, sixth, and seventh choose a searchable player or Other-player name; the other three choose one of the existing clubs.

Before reveal, the public table leaderboard exposes only each participant's name, submission time, predicted champion, and 0-point total. Prediction IDs, positions 2–20, and all seven spotlight picks stay private to the receipt browser and administrator. After reveal, the main leaderboard compares each table with the active standings. Its 5–3–1 tiers have a maximum of 100. A separate spotlight page tracks fun accuracy and never changes table points. Let N be the current number of active, nondeleted season brackets. Accuracy points are max(0, N + 1 - outcome rank). Overall accuracy sums only resolved categories. Pending categories remain unavailable. Equal overall scores share a competition rank.

Team underdog index is average predicted position minus actual position. Team overrated index is the inverse, and the largest value ranks first. Top scorer, top assister, and most clean sheets use the selected subject's occupied result rank. Underdog player ranks reviewed FotMob season ratings from high to low. Overrated player ranks them from low to high. A future owner-run Codex automation may acquire FotMob or Transfermarkt data offline, review it, and enter these five outcomes. The app has no runtime FotMob access. The owner-selected 2026-08-13 selector snapshot supplies 582 players and 582 local portraits; it is internally reconciled and not independently official-site verified. Other player remains available. Production stays on the August 8 seed baseline of 587 active players and 580 portrait paths until the refreshed application is deployed and the approved seed runs.

Primary users are invited participants on mobile devices and one owner-administrator. Arsenal v Coventry City's verified 2026-08-21T19:00:00.000Z opening kickoff is the persisted, non-extendable submission ceiling for the 2026/27 season. The owner can close earlier, manually lock, reveal early, delete erroneous entries, manage standings/import visibility, and confirm or undo final status. Login uses the admin username by default with a server-only salted PBKDF2 password hash; ADMIN_SECRET is a migration fallback only. Deleting a prediction cascades through its 20 table items and seven spotlight picks, after which the same normalized name may submit again and consensus scores derive from the remaining entries.

The user-facing visual system uses the Premier League's official purple, #37003c, with cyan #05f0ff, green #00ff87, and pink #ff2882 accents and an original Dranx mark. The official Premier League logo is not included.
