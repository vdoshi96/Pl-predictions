Project

Dranx Prediction League is an unofficial prediction game for a private invited group covering the 2026/27 English Premier League. It contains the original season-table and Spotlight prediction game plus a separate Win Streak mini game for Matchweeks 2–38. In Win Streak, a participant makes one immutable club-to-win pick per round. A win extends the current streak and restricts that club; a draw or loss resets the current streak and unlocks all clubs; a missed or void round preserves it. The public Win Streak leaderboard is available without a profile and shows best streak, current streak, and the current-matchweek pick. A display name plus a secure browser receipt, not an account or login, controls future picks.

In the original game, a participant completes one immutable three-stage entry: order exactly 20 clubs and enter one display name, choose all seven spotlight predictions, then review the whole package before submission. The categories are top scorer, top assister, most clean sheets, underdog team, overrated team, underdog player, and overrated player. The first, second, sixth, and seventh choose a searchable player or Other-player name; the other three choose one of the existing clubs. The initial entry response contains no player catalogue or portrait paths. Stage 2 lazily loads active current-season players through a same-origin route; player search requires two normalized characters, shows at most 20 matches while announcing the total, and always retains Other player.

Every Win Streak matchweek uses one round-wide pick deadline equal to the earliest kickoff among its ten persisted fixtures. The PostgreSQL clock enforces that deadline for profile creation and picks, so selecting a later-playing club never extends the round's window.

Before reveal, / remains the prediction form, and the public table leaderboard exposes only each participant's name, predicted champion, and 0-point total. Prediction IDs, positions 2–20, and all seven spotlight picks stay private to the receipt browser and administrator. After reveal, / becomes the live Premier League table versus the league's average prediction. The main leaderboard compares each table with the active standings through a top-three podium and a dense shared-rank table. It shows movement from the previous meaningful standings snapshot, and its 5–3–1 tiers have a maximum of 100. A separate spotlight page tracks fun accuracy and never changes table points. Its default category view groups picks across all seven categories, its entry view retains the per-entry accuracy list and category sorts, and its matrix view compares all seven picks across entries. Let N be the current number of active, nondeleted season brackets. Accuracy points are max(0, N + 1 - outcome rank). Overall accuracy sums only resolved categories. Pending categories remain unavailable, attested outside-range subjects truthfully receive zero, and equal scores share a competition rank.

Team underdog index is average predicted position minus actual position. Team overrated index is the inverse, and the largest value ranks first. Each index uses every complete table prediction, but each ranking includes only the distinct clubs picked for that opinion category. Top scorer, top assister, and most clean sheets use the selected subject's occupied league-wide result rank. Underdog-player picks rank by reviewed season rating from high to low; overrated-player picks use the same factual ratings from low to high. Each player direction has its own distinct picked-subject pool. The owner enters those five factual views manually through /admin/results, backed by sealed immutable goals, assists, clean_sheets, and shared player_ratings snapshots with exact pinned Other-name aliases. The app has no runtime football-data access. The owner-selected 2026-08-20 selector snapshot supplies 580 players and 578 local portraits; Ryan McAidoo and Luc De Fougerolles use the silhouette fallback. It is internally reconciled and not independently official-site verified. The server SQL-filters active catalogue rows, and submission validation queries only player IDs referenced by the submitted picks. Other player remains available. Production uses the supported August 20 catalogue seed: 580 active players, 578 local portrait paths, and the two documented silhouette fallbacks.

Administrator data entry accepts reviewed text without weakening existing write boundaries. The standings desk parses and resolves all 20 clubs, shows an active-table diff, and submits only a valid complete permutation through the existing atomic action. The results desk can seed subjects from complete submissions, parse reviewed lists, preserve unmatched lines for correction, and combine review, exact attestation, save, and publish. Publishing always targets the immutable snapshot returned by the successful save; if the publish transition fails, the saved working draft remains available for retry.

Primary users are invited participants on mobile devices and one owner-administrator. The browser retains a validated season-local draft until submission, and untouched A–Z tables require explicit intent. Arsenal v Coventry City's verified 2026-08-21T19:00:00.000Z opening kickoff is the persisted, sole timed submission cutoff for the 2026/27 season. There is no configurable earlier deadline. Settings always show the fixed instant in America/Chicago plus a selectable Eastern, Central, Mountain, Pacific, or UTC rendering with DST-aware labels. The owner may close earlier only through irreversible typed manual lock or early reveal, requiring exact LOCK or REVEAL; both reveal predictions and permanently close submissions. The owner can also delete erroneous entries, manage standings/import visibility, enter and version factual result datasets, and confirm or undo exact final pointers. Login uses the admin username by default with a server-only salted PBKDF2 password hash; ADMIN_SECRET is a migration fallback only. Deleting a prediction cascades through its 20 table items and seven spotlight picks, after which the same normalized name may submit again and consensus scores derive from the remaining entries.

The user-facing visual system uses the Premier League's official purple, #37003c, with cyan #05f0ff, green #00ff87, and pink #ff2882 accents and an original Dranx mark. The official Premier League logo is not included. The project owner supplied and directed use of 20 transparent local PNG club badges; TeamMark displays them with contain sizing and an accessible initials fallback, while the original monograms remain rollback-only for the first PNG release.

Constraints: one Next.js/Vercel application, Vercel-managed Neon, and one atomic submission with 20 table rows and seven category rows. Win Streak adds durable rounds, fixtures, receipt-bound profiles, and picks without changing that submission interface. The app has no end-user accounts, runtime football API, production scraper, cron, or extra personal data. It remains compatible with free and Hobby tiers. Operational identifiers retain their existing pl-predictions names. /rules explains table points, separate spotlight accuracy, and pending outcomes; docs/WIN-STREAK.md is the canonical Win Streak rules and operations record.
