Project

Dranx Prediction League is an unofficial prediction game for a private invited group covering the 2026/27 English Premier League. A participant completes one immutable three-stage entry: order exactly 20 clubs and enter one display name, choose all seven spotlight predictions, then review the whole package before submission. The categories are top scorer, top assister, most clean sheets, underdog team, overrated team, underdog player, and overrated player. The first, second, sixth, and seventh choose a searchable player or Other-player name; the other three choose one of the existing clubs.

Before reveal, the public leaderboard exposes only each participant's name, submission time, predicted champion, and 0-point total. Prediction IDs, positions 2–20, and all seven spotlight picks stay private to the receipt browser and administrator. After reveal and scoring activation, it compares every entry with the active actual table, adds any available spotlight rank points, and shows the champion pick's current actual position. A 5–3–1 exact/nearby/half table is worth up to 100; each spotlight result rank scores 20 down to 1, making the full maximum 240. Equal results share rank.

Team underdog index is average predicted position minus actual position; team overrated index is the inverse, and the largest value ranks first. Top scorer, top assister, and most clean sheets use the chosen player's or club's occupied result-list rank. Underdog player ranks reviewed FotMob average season ratings descending and overrated player ranks them ascending, but no runtime or automated FotMob access is authorized or implemented. Only the two team expectation outcomes are currently derivable; the other five remain pending reviewed source-neutral rankings. The owner-provided 2026-08-08 selector snapshot supplies 587 players across all 20 clubs and 580 local portraits; seven players use the generic silhouette, and Other player remains available for unavailable or newly added players. The roster snapshot does not supply spotlight outcomes.

Primary users are invited participants on mobile devices and one owner-administrator. Arsenal v Coventry City's verified 2026-08-21T19:00:00.000Z opening kickoff is the persisted, non-extendable submission ceiling for the 2026/27 season. The owner can close earlier, manually lock, reveal early, delete erroneous entries, manage standings/import visibility, and confirm or undo final status. Login uses the admin username by default with a server-only salted PBKDF2 password hash; ADMIN_SECRET is a migration fallback only. Deleting a prediction cascades through its 20 table items and seven spotlight picks, after which the same normalized name may submit again and consensus scores derive from the remaining entries.

The user-facing visual system uses the Premier League's official purple, #37003c, with cyan #05f0ff, green #00ff87, and pink #ff2882 accents and an original Dranx mark. The official Premier League logo is not included. The project owner supplied and directed use of 20 transparent local PNG club badges; TeamMark displays them with contain sizing and an accessible initials fallback, while the original monograms remain rollback-only for the first PNG release.

Constraints: one Next.js/Vercel application, Vercel-managed Neon, exactly 20 table rows plus seven category rows in the guarded atomic submission, no end-user accounts, no runtime football API, no production scraper, no cron, no extra personal data, and compatibility with free/Hobby tiers. Operational repository, Vercel, database, and environment identifiers retain their existing pl-predictions names. /rules is the public canonical explanation of scoring and pending data status.
